Цифровые пропуска

Для работы с пропусками войдите через AA ID.

Доступные пропуска

Ваш пропуск и пропуска, к которым владельцы предоставили доступ. Разрешения можно изменить в настройках AA ID. Номер запрашивается отдельно и скрывается через 30 секунд.

Подключить свой пропуск

Запросите код способом подтверждения, настроенным в МИРЭА, и введите его здесь. Сервер сохранит выданный МИРЭА пропуск. Повторный выпуск может заменить предыдущую привязку устройства. Сайт показывает номер; для прохода по NFC нужно приложение с поддержкой этого API.
